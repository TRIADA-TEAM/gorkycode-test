# Голосовой ассистент для задач и встреч

Прототип принимает свободные текстовые и голосовые команды, создает задачи и
встречи, показывает планы за период и ищет старые события.

## Локальный запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python -m scripts.migrate
uvicorn app.main:app --reload
```

Откройте `http://127.0.0.1:8000`. Для обработки текстовых команд заполните
`GIGACHAT_AUTH_KEY` в `.env`. Для голосового ввода также укажите
`POLZA_API_KEY`: аудио распознаётся моделью
`openai/whisper-large-v3-turbo` через Polza, после чего полученный текст
обрабатывается тем же путём, что и обычная текстовая команда.

Голосовой поток:

```text
браузер → POST /api/assistant/audio → Polza Whisper → текст → GigaChat → команда
```

По умолчанию используются:

```dotenv
POLZA_API_URL=https://polza.ai/api/v1
POLZA_STT_MODEL=openai/whisper-large-v3-turbo
POLZA_STT_LANGUAGE=ru
DIALOGUE_TTL_MINUTES=30
```

Ключ Polza должен начинаться с `pza_`. Он хранится только в `.env` и никогда
не передаётся браузеру. Приложение принимает короткие записи WebM/Opus, OGG,
MP3, MP4/M4A и WAV размером до `MAX_AUDIO_BYTES`. Если конкретный браузерный
WebM будет отклонён провайдером, потребуется отдельная конвертация через FFmpeg;
в текущую версию она намеренно не включена.

## Docker

```bash
cp .env.example .env
docker compose up -d --build
```

SQLite хранится в persistent Docker volume и не пропадает при перезапуске
контейнера. При старте контейнер автоматически применяет миграции Alembic.
Команда `python -m scripts.migrate` также безопасно принимает старую базу,
ранее созданную приложением через `create_all()`, если её схема совместима.
Seed-данные и внешний CSV не используются. Перед приложением следует настроить
Caddy или Nginx с HTTPS: браузер предоставляет микрофон только в безопасном
контексте.

## Проверка

```bash
pytest -q
```

Примеры запросов:

- `Напомни завтра в 10 позвонить Ивану`;
- `Добавь встречу с командой завтра в 15:00`;
- `Что у меня на этой неделе?`;
- `Найди задачу про договор`.

Подробные решения и порядок разработки описаны в `IMPLEMENTATION_PLAN.md`.
